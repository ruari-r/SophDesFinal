"# SophDesFinal" 

This is a project I completed for my Final Project in my Computer Organization and Microprocessors course at Binghamton University
This project required me to learn many new things and strengthen my embedded programming skills using Bare Metal C. This gave me my lowest-level coding experience to date, working directly with registers and ports.
I also got the chance to delve into some control systems and feedback work, creating PID controllers to account for any variation in the drive motors. 
I also learned how to work with FSMs and optimization, where I created an overall control FSM that provided the decision-making structure for the bot and a completely non-blocking FSM to read data from 2 ultrasonic sensors simultaneously.
